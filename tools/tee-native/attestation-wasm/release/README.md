These are the exact Nitro validator artifacts qualified with extension 1.2.0 and the measured enclave. The Railway image copies them into `attestation-wasm/pkg`; it does not fetch executable code at runtime. Source: `../src/lib.rs`, `../Cargo.lock`; build: `../../build-attestation.py` (Rust 1.95.0, wasm-bindgen 0.2.104). `SHA256SUMS` pins the bytes used by both the API and extension. Rebuilds require checking those hashes or requalifying the validator.
